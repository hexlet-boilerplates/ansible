# ansible

## Requirements

Нужен [mise](https://mise.jdx.dev), он ставит ansible-core, ansible-lint и остальные инструменты из `mise.toml`.

```bash
make install
```

`make install` ещё ставит git-хуки через hk.

## Run

```bash
make run-playbook
```

## Lint

```bash
make lint
```
